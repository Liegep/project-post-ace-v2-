# Direcao escolhida do Kanban V2

## Escolha aprovada

A direcao preferida para o Kanban da V2 e a primeira versao mais clean.

Motivos principais aprovados:

- fundo com degradê suave
- visual mais leve
- composicao mais elegante
- barra lateral com boa presenca

## Barra lateral

A barra lateral do workspace admin deve existir como uma gaveta recolhivel.

Ela pode:

- ficar aberta
- ficar fechada
- servir de navegacao para outras areas do sistema

## Itens sugeridos para a barra lateral

- clientes
- pautas
- faturamento
- relatorios
- biblioteca
- configuracoes

Ela deve funcionar como uma navegacao pratica do ecossistema, sem pesar no Kanban.

## Busca dentro do Kanban admin

Dentro do Kanban de cada cliente, precisa existir busca de cards.

Objetivo:

- localizar rapidamente um card especifico
- filtrar conteudos daquela conta
- reduzir tempo de procura no quadro

Essa busca deve considerar pelo menos:

- titulo do card
- texto principal
- tags
- status

## Busca na area do cliente

O portal do cliente tambem pode ter busca para localizar cards e filtrar conteudos.

Isso e importante para clientes com muito volume de material.

## Regra de permissao da busca

A busca do cliente nao deve ser obrigatoria para todas as contas.

Ela deve ser controlada nas configuracoes de cada cliente.

Ou seja:

- no admin, a Liege liga ou desliga a busca daquela conta
- quando ligada, o cliente ve busca e filtros
- quando desligada, a interface do cliente fica mais simples

## Impacto no desenho da V2

Com essa decisao, o Kanban V2 passa a ter:

- visual base da versao mais clean
- degradê suave no fundo
- barra lateral recolhivel
- gaveta lateral de apoio
- busca no workspace admin
- busca opcional no portal do cliente

Isso preserva o ar premium do sistema e melhora a usabilidade real.
